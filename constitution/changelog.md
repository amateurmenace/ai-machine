# Constitution Changelog

All notable changes to the community constitution. Adopted versions are never
edited in place; each change produces a new `constitution-v<version>.md`.

## v1.0 — 2026-09-20 — draft

Initial draft, adapted from the sample constitution in the *Community-Owned AI*
guide (Appendix B). Twenty principles covering public service, evidence,
uncertainty, the public record, time, pluralism, civic neutrality, attribution,
privacy, transparency, authority, accessibility, general utility, correction,
human agency, source hierarchy, conflicts, data freshness, fabricated consensus,
and verifiability.

Status: **not ratified**. This is the starting point for community review, not
an adopted document. A community adopting this platform should expect to edit
it before ratifying v1.1.

Known gaps to resolve before ratification:

- No principle yet on how the assistant should handle requests to draft
  testimony, public comment, or advocacy material for a resident. Principle 7
  (Civic Neutrality) and Principle 13 (General Utility) pull in opposite
  directions here and the tie is not broken.
- No principle on non-English service levels beyond Principle 12
  (Accessibility). If the community commits to a language, say so explicitly.
- No stated retention period for request logs. Governance says question text
  stays private; it does not say for how long.
